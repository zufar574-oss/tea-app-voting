# Голосование за следующий чай

Веб-приложение для дегустации. Ведущий вводит три варианта и показывает QR, до 6 гостей голосуют одной кнопкой со своих телефонов, ведущий нажимает «Подсчитать» и видит три числа.

- Стек: HTML, CSS, Vanilla JavaScript. Хостинг: GitHub Pages. База: Supabase.
- Сайт (страница ведущего): https://zufar574-oss.github.io/tea-app-voting/
- Страница гостя: тот же адрес с `?poll=<id>`. Ссылку гостям даёт QR, вручную её вводить не нужно.
- Без `?poll=` открывается страница ведущего, с `?poll=<id>` страница гостя.
- Требования, макеты и ход работы: SPEC.md, DESIGN.md, PROJECT.md, STATUS.md.

## Из чего состоит сайт

Все восемь файлов лежат в корне репозитория `tea-app-voting`. Загружать нужно все сразу.

| Файл | Что делает |
|---|---|
| `index.html` | Все экраны (форма, QR, итоги, страница гостя) и подключение файлов |
| `style.css` | Внешний вид: молочный фон, чёрный текст |
| `config.js` | Адрес проекта Supabase и публичный ключ |
| `api.js` | Все запросы к Supabase |
| `qrcode.js` | Готовая библиотека qrcode-generator (MIT), без правок |
| `host.js` | Страница ведущего: форма, QR, счётчик, подсчёт, итоги, новый раунд |
| `guest.js` | Страница гостя: варианты, голос, `device_id` |
| `app.js` | Выбирает страницу ведущего или гостя по адресу |

SQL для базы лежит отдельно (папка `sql/`) и на сайт не загружается: `01_tables.sql`, `02_rls_polls.sql`, `03_rls_votes.sql`.

**Номер версии.** У подключаемых файлов в `index.html` стоит `?v=N` (сейчас 12). Если меняешь любой файл, увеличь N во всех подключениях, иначе телефон может взять старые копии из кэша.

## Как развернуть с нуля

1. **Supabase.** Создай проект на supabase.com. В настройках проекта (Project Settings → API Keys, или кнопка Connect) найди адрес проекта вида `https://….supabase.co` и **публичный** ключ (`sb_publishable_…`, у старых проектов `anon`).
   Секретный ключ (`sb_secret_…` или `service_role`) никому не присылай и никуда не вставляй.
2. **База.** В SQL Editor по очереди запусти `01_tables.sql`, `02_rls_polls.sql`, `03_rls_votes.sql`. Каждый файл запускается один раз, при повторном запуске будет ожидаемая ошибка «already exists».
3. **Подключение.** В `config.js` впиши адрес проекта и публичный ключ.
4. **Сайт.** Создай на GitHub публичный репозиторий, загрузи все восемь файлов (Add file → Upload files → Commit changes). В Settings → Pages выбери «Deploy from a branch», ветку `main`, папку `/ (root)`. Через минуту-две сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.
5. Если адрес сайта другой, ссылка в QR подстроится сама: она строится из адреса страницы ведущего.

## Как проверить (контрольные примеры из SPEC.md)

Проверяй на компьютере и на телефонах: iPhone/Safari и Android/Chrome. Для гостей нужны отдельные устройства или приватные вкладки: у каждого браузера свой `device_id`.

1. **Создание.** Открой адрес сайта, заполни три поля, нажми «Создать»: появится QR, в таблице `polls` новая строка со статусом `open`. С пустым полем: подсветка и «Заполните все три варианта».
2. **Голос и передумывание.** Отсканируй QR другим телефоном, нажми вариант 1, затем вариант 3: «Голос принят», отмечен вариант 3, в `votes` одна строка этого устройства с `choice = 3`.
3. **Счётчик и итоги.** Проголосуй с двух-трёх устройств, на странице ведущего нажми «Обновить»: число проголосовавших верное. Нажми «Подсчитать»: на итогах три числа, их сумма равна числу строк в `votes`, у голосования `status = closed`.
4. **Закрыто.** После «Подсчитать» гость нажимает вариант или открывает QR заново: «Голосование закрыто».
5. **Не найдено.** Адрес с несуществующим `?poll=…` (например, `?poll=abc`): «Голосование не найдено».
6. **Новый раунд.** На итогах «Новый раунд»: форма с прежними текстами. «Создать» делает новое голосование с новым QR и счётчиком с нуля, старое остаётся `closed`.
7. **Нет интернета.** Отключи интернет у ведущего и нажми «Создать» (или «Подсчитать», «Обновить»): сообщение об ошибке, тексты на месте. У гостя без интернета: «Голос не отправился…» или «Не удалось загрузить…».

### Проверка правил доступа (RLS) руками

В SQL Editor от имени роли `anon`. Каждый блок запускай отдельно, все заканчиваются `rollback`, данные не остаются.

Создать голосование сразу закрытым нельзя (ожидаем ошибку `row-level security`):
```sql
begin;
set local role anon;
insert into polls (option_1, option_2, option_3, status) values ('a', 'b', 'c', 'closed');
rollback;
```

Голос в закрытое голосование не проходит (ожидаем ошибку `row-level security`):
```sql
begin;
insert into polls (option_1, option_2, option_3, status) values ('a', 'b', 'c', 'closed');
set local role anon;
insert into votes (poll_id, device_id, choice) select id, 'dev-2', 1 from polls where option_1 = 'a';
rollback;
```

Удалить голоса нельзя (ожидаем `permission denied for table votes`):
```sql
begin;
set local role anon;
delete from votes;
rollback;
```

## Перед дегустацией

- Открой страницу ведущего с телефона, которым будешь показывать QR, и сделай пробный раунд с одним тестовым голосом.
- Бесплатный проект Supabase может приостановиться после долгого простоя. Если сайт пишет «Не удалось загрузить…», зайди в панель Supabase и проверь, что статус проекта Healthy, при необходимости восстанови проект.
- Интернет нужен всё время: у ведущего и у гостей. Офлайн-режима нет.

## Частые проблемы

| Что видишь | Что проверить |
|---|---|
| Пустой экран на странице ведущего | Загружены ли все восемь файлов. Открой `…/app.js` в браузере: должен показаться текст кода, а не 404. Если файлы на месте, закрой вкладку и открой сайт в приватной вкладке (телефон мог взять старые файлы из кэша). Красная строка в консоли браузера (F12 → Console) покажет точную причину |
| «Не удалось загрузить. Проверьте интернет…» у гостя | Нет интернета, либо в `config.js` неверный адрес или ключ, либо проект Supabase приостановлен |
| «Голос не отправился…» при рабочем интернете | Правила доступа: запущен ли `03_rls_votes.sql`; не закрыто ли голосование |
| «Не удалось обновить» или «Не удалось подсчитать» при рабочем интернете | Правила доступа: запущены ли `02_rls_polls.sql` и `03_rls_votes.sql`, есть ли право читать `votes` и менять `polls` |
| QR открывает форму ведущего, а не страницу гостя | В адресе нет `?poll=<id>`: ссылку открыли без параметра |
| «Голосование не найдено» | Ссылка испорчена, неполная или такого голосования нет в базе |
| «Голосование закрыто» | Ведущий уже нажал «Подсчитать». Голосовать можно только в новом раунде |

## Ограничения первой версии

- У страницы ведущего нет пароля. Защита доступа в базе по варианту А: один публичный ключ, база не отличает ведущего от гостя. Запрет «гость не видит чужие голоса и не меняет статус» держится на интерфейсе, а не на защите базы. Для шести знакомых гостей риск принят.
- Один голос на устройство. `device_id` хранится в браузере: другой браузер, приватная вкладка или очистка данных сайта считаются новым устройством.
- Нет резервного ввода голоса ведущим при плохом интернете.
- Если ведущий обновит или закроет страницу, QR-экран пропадёт, голосование останется в базе, а продолжить его нельзя: создай новое.
- После обновления страницы гость не видит отметку своего прошлого выбора, хотя голос в базе остаётся.
- История прошлых голосований в приложении не показывается, старые голосования остаются только в базе.
